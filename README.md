> **Overview:** This document outlines my confirmed technical responsibilities and contributions during my 8 months working as a Full-Stack Developer on **Harigurus** ([harigurus.com](https://harigurus.com)), an online platform for booking traditional Hindu religious ceremonies, astrology consultations, and ceremonial services.  
> *Note: Harigurus source code and proprietary client implementations remain private with the company. This case study documents my specific engineering responsibilities and confirmed functional contributions.*

---

## Confirmed Role & Technical Scope

During my 8-month tenure as a full-stack developer on Harigurus, my confirmed work spanned both frontend and backend systems:

- **Frontend Development (React):** Built and maintained customer-facing user interface workflows, focusing on appointment scheduling and service booking flows.
- **Backend Development (Node.js & Express):** Developed and integrated REST API endpoints handling booking submissions and customer data.
- **Payment Processing (Razorpay):** Integrated Razorpay payment workflows to handle online transactions for ceremony bookings.
- **SMS & Communications (Twilio):** Integrated Twilio SMS services for automated appointment confirmations and customer notifications.

---

## Core Implemented Systems

### 1. Appointment Booking Workflow (React)
- Implemented multi-step booking interfaces allowing customers to select ceremonies, choose available dates and time slots, and specify requirements.
- Developed form validation and client-side error handling to ensure complete customer contact and address information before order submission.
- Maintained responsive layouts across desktop and mobile devices.

### 2. Backend API Services (Node.js / Express)
- Created backend route handlers and controller logic for processing incoming appointment requests.
- Maintained integration between user details, booking records, and the underlying database models.

### 3. Payment Integration (Razorpay)
- Implemented Razorpay payment processing into the booking checkout flow.
- Managed payment verification callbacks and status updates linking completed transactions to confirmed booking records.

### 4. SMS Notifications (Twilio)
- Integrated the Twilio SMS API to send automated booking confirmation messages to customers upon successful appointment creation.
- Configured delivery payloads and message formatting for booking reminders and status alerts.
